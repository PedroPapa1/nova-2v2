# Nova 2v2

Chaveamento publico do campeonato Nova 2v2.

- `index.html`: pagina publica somente leitura.
- `admin.html`: pagina local para editar placares e baixar o `data.json`.
- `data.json`: estado publicado do chaveamento.
- `logo.png`: logo original da Nova usada no topo do site.

## Regras

- Primeira Fase: 32 duplas, MD1
- Oitavas de Final: 16 duplas, MD1
- Quartas de Final: 8 duplas, MD3
- Semifinais: 4 duplas, MD3
- Disputa de 3º e 4º lugar: 2 duplas, MD3
- Grande Final: 2 duplas, MD5

## Atualizar resultados

1. Abra `admin.html`.
2. Edite os placares.
3. Clique em `Baixar data.json`.
4. Substitua o `data.json` do repositorio pelo arquivo baixado.
5. Envie para o GitHub.
